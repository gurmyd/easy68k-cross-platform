The surface hash is the harness's: SHA-256 of `<width>x<height>:` and the pixels. The surface's
pixels are opaque little-endian `$AABBGGRR` words, so their bytes are the RGBA bytes that
`getImageData` returns from the Output canvas, whose backing store has one pixel per surface pixel.
