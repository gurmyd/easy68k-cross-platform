  4. A path of a mount that is not mounted, or a text that is not a VPath, is returned as given,

## 4. `fs/history-memory.ts` and the layer rule

P4.4 says `fs/history-memory.ts` imports the development dependency `fake-indexeddb`. The layer
rule lets `fs/` import no npm package, and a file that is not a `*.test.ts` gets no test allowance,
so N3's import will fail `npm run lint`. P2.4's list of `eslint.config.js` changes has no
allowance for it, so N0 did not add one; N0's stub imports nothing. Request:
`docs/requests/N0.md` section 7, item 1.

## 5. Electron's `plugins` does not gate its PDF viewer (R5)

R5 says `webPreferences.plugins: true` "enables only its PDF viewer" and that content windows keep
`plugins: false`. Found (PDF spike, `docs/requests/N0.md` 5.1 and 5.3): in Electron 45.4.1 the PDF
viewer draws a `blob:` PDF in a window with `plugins: false` as well. N0 made both changes of the
entry (`plugins: true` in `APP_WEB_PREFERENCES`, `plugins: false` set explicitly in
`CONTENT_WEB_PREFERENCES`); `tests/desktop/dev/unit.spec.ts` asserts both constants.
At run time `webContents.getLastWebPreferences()` in Electron 45.4.1 does not report `plugins` at
all (it came back `undefined` for both windows), so `security.spec.ts` and `protocol.spec.ts` no
longer read it there (repair round 1; asserting it made `npm run desktop:test -- dev` red).
`security.spec.ts` checks the effect in the application window instead: the page sees
`navigator.pdfViewerEnabled === true`. That proves the viewer is present in the application window,
not that the flag is set: the N0 verification measured in Electron 45.4.1 that
`navigator.pdfViewerEnabled` is `true` whether `plugins` is `true`, `false` or absent, and the
comment in `security.spec.ts` says so since the gate's second round (it said before, wrongly, that
Chromium reports the viewer only while plugins are on). The help window runs with JavaScript off,
so the page cannot be asked; its value is covered only by the constant check.
What R5 wanted to keep out of content windows (a plugin) is kept out by Electron having none but the
PDF viewer; the viewer itself is not kept out by the flag.
